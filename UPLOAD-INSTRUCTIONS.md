# How to Upload Your Updated Website

## Files to Upload to GitHub:

You need to upload these NEW files:
- calendar.html
- iuc.html
- petition.html
- information.html
- contacts.html
- Kidsplayingdirt.png (hero image)

And REPLACE these existing files:
- index.html (updated)
- styles.css (updated)

## Steps:

1. Go to your GitHub repository: https://github.com/danwozniak23-maker/savemorganvalley (or whatever you named it)

2. Click "Add file" → "Upload files"

3. Drag and drop ALL the files listed above

4. Scroll down and click "Commit changes"

5. Wait 1-2 minutes for GitHub Pages to rebuild

6. Visit savemorganvalley.com to see your new site!
